# ملحمة نصر أكتوبر 1973

لعبة استراتيجية تفاعلية مبنية بـ React + Vite.

## تشغيلها كموقع

بعد تفعيل GitHub Pages مرة واحدة من:

**Settings → Pages → Build and deployment → Source → GitHub Actions**

سيتم نشر الموقع تلقائيًا عند كل تحديث على `main`.

الرابط المتوقع:
https://xXGAN2Xx.github.io/The-Great-October-Victory-Sandoub-Complex-Kindergarten/

## تشغيلها مباشرة من GitHub

من تبويب **Actions** اختر:

**Deploy to GitHub Pages → Run workflow**

ويمكنك إعادة النشر يدويًا بدون تعديل الكود.

## تشغيلها محليًا

```bash
npm install
npm run dev
```

ثم افتح:
http://localhost:3000

## فحص المشروع

```bash
npm run lint
npm run build
```
