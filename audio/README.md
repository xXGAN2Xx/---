# موسيقى الخلفية

ضع هنا ملف الموسيقى الذي تريده باسم:

`october-6.mp3`

الصيغ المقبولة من داخل اللعبة أيضًا: MP3 / OGG / WAV.

عند وجود `october-6.mp3` سيتم استخدامه تلقائيًا كموسيقى خلفية بدل الموسيقى الاصطناعية للعبة.

يمكن كذلك اختيار أي ملف صوتي من زر **موسيقى الخلفية الخاصة بك** في غرفة العمليات.
